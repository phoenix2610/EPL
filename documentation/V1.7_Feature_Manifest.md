# EPL v1.7 — Feature Manifest & Changelog

This document outlines the major architectural and frontend upgrades introduced in EPL version 1.7. The primary focus of this release was **High-Fidelity Frontend Parity**, moving the language from a documentation tool to a production-grade web prototyping engine.

---

## 1. Automated Design System
The core compiler (`codegen.c`) no longer relies on hardcoded style strings. It now implements a sophisticated asset injection pipeline.

- **`epl_base.css` Integration**: Automatically injects premium design tokens (Syne & Space Mono fonts, glassmorphism, and dark-mode depth) into every page.
- **`app.js` Runtime**: Every page now ships with a native JS runtime that handles scroll reveals, custom cursor tracking, and interactive micro-animations.
- **Zero-Boilerplate**: You no longer need to write `<style>` or `<script>` tags inside `.epf` files. The compiler handles all "Formal" layout styling automatically.

## 2. Full Page Modulus (Responsive Layout)
We shifted from a restricted 1200px "boxed" layout to a full-bleed immersive experience.
- **Edge-to-Edge Canvas**: Pages now utilize the full viewport width by default, essential for "Classy" landing pages and dashboards.
- **Hero Sections**: Automated handling of hero content with `clamp()` based responsive typography.
- **No Wasted Space**: Removed legacy sidebar padding and restrictive margins to allow for modern, industrial-grade layouts.

## 3. The "Apex" Navigation System
The compiler now handles multipage orchestration with a premium top-navigation bar.
- **Automatic Link Discovery**: If you use `make page` multiple times, the compiler builds the Navbar for you based on your `.epbind` manifest.
- **Rotating Logo**: Integrated the official `EPL_logo.png`. As you scroll, the logo performs a "Coin Spin" (3D RotateY) animation proportional to the scroll depth.
- **Sticky Glassmorphism**: The nav bar is fixed with a 20px backdrop-blur effect, ensuring visibility across long content pages.

## 4. Premium Component Upgrades
The standard keywords have been overhauled to minimize writable code while maximizing visual impact:

| Feature | Upgrade Detail |
| :--- | :--- |
| **`make stat`** | Now features high-contrast "Space Mono" values and subtle glowing hover states. |
| **`make chart`** | Seamlessly integrates with `Chart.js` v4.4, providing colorless/static-free data viz by default. |
| **`make report`** | Implements monospaced tabular layouts optimized for technical benchmarks and roadmaps. |
| **`make canvas3d`** | Native support for Three.js orbital rings and task node visualizations. |

## 5. Industrial Micro-Interactions
- **Custom Cursor**: A multi-layered magnetic cursor (`cursor` dot + `cursor-ring`) follows the user, changing state when hovering over interactive elements.
- **Scroll Reveals**: Elements now "fade up" into view as the user scrolls, controlled by a high-performance Intersection Observer in the generated runtime.

---

### How to use v1.7 effectively:
Instead of manually injecting HTML via `paragraph`, you can now rely on the core keywords to generate beautiful code:

```text
make page saved as "dashboard.html" styled as "dark"
make stat labelled "COMPILE TIME" valued at 223
make chart named "System Performance" plotting cpu_data
```

The compiler will take care of the **Navbar**, **Styling**, **Animations**, and **Mobile Responsiveness** automatically.
