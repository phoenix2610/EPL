# EPL Frontend Framework (.EPF) Explainer

The `.epf` (English Programming Frontend) extension is EPL's native web dashboarding and GUI generation engine. It allows developers to compile logic written in plain English directly into responsive, interactive HTML, CSS, and JavaScript, entirely bypassing traditional web frameworks.

This document outlines the core keywords, syntax, and internal mechanics of the `.epf` engine.

---

## Core Mechanics & Execution

1. **Integrated Compilation:** `.epf` files are processed by the exact same C compiler (`interpreter.c`, `parser.c`, `lexer.c`) as standard `.ep` logic files. This means you can run native EPL computations (e.g., `set total as a plus b`) directly alongside your UI definitions.
2. **Code Generation:** The `codegen.c` module intercepts specific frontend AST nodes and translates them into semantic HTML5 and JavaScript (Chart.js / Three.js).
3. **Orphan Sweeping:** The `.epbind` manifest automatically tracks all assets (HTML, CSS, JS) generated by a specific `.epf` file. If you delete a page from your script or rename it, the interpreter will automatically delete the old files during the next compilation, ensuring zero directory clutter.

## 1. Global Setup Keywords

### `describe dashboard as "<Title>"`
Defines the global title of the dashboard or application.
*   **Example:** `describe dashboard as "A.R.E.S. Command Nexus"`
*   **Output:** Sets the internal title metadata and the `<title>` tag for the HTML head.

### `make page saved as "<filename>" styled as "<theme>"`
Initializes a new standalone HTML file. All subsequent UI keywords will be written into this page until a new `make page` is declared or the file ends.
*   **Example:** `make page saved as "index.html" styled as "dark"`
*   **Output:** Creates the file, injects the standard `.epl-shell-layout`, and imports necessary JS libraries (Chart.js, Three.js).

---

## 2. Structural & Layout Keywords

### `section "<Section Title>"` ... `!`
Creates a designated visual container to group components together. It requires an exclamation mark `!` to close the scope.
*   **Example:**
    ```epl
    section "Global Metrics"
        # Components go here
    !
    ```

### `row` ... `!`
Initiates a responsive CSS flex/grid layout. Any components placed inside a row will align horizontally and wrap dynamically based on screen width. Must be closed with `!`.
*   **Example:**
    ```epl
    row
        # Stats and charts go here
    !
    ```

---

## 3. Data Visualization & Widgets

### `make stat "<Label>" from <Variable>`
Generates an industrial-style numeric "Stat Card" bound to an EPL variable.
*   **Example:** `make stat "Active Nodes" from total_nodes`

### `make table from <ListVariable> titled "<Title>"`
Generates a responsive HTML table populated by an EPL list.
*   **Example:** `make table from employee_names titled "Active Roster"`

### `make bar chart for x axis as <Var> and y axis as <Var> titled "<Title>"`
Compiles native EPL lists into a dynamic Chart.js Bar Chart.
*   **Example:** `make bar chart for x axis as months and y axis as revenue titled "Q1 Revenue"`

### `make line chart for x axis as <Var> and y axis as <Var> titled "<Title>"`
Compiles native EPL lists into a dynamic Chart.js Line Chart with built-in tension and curve smoothing.

### `make report for <Var> titled "<Title>"`
Generates a comprehensive tabular dataset layout intended for heavy data reporting.

---

## 4. Typography & Injection Keywords

### `heading "<Text>"`
Injects an `<h2>` element for large sub-titles.

### `subheading "<Text>"`
Injects an `<h3>` element for smaller titles.

### `bold "<Text>"`
Injects an inline `<strong>` element for emphasized text.

### `paragraph "<Text>"`
Injects a `<p>` tag containing the string. 
*   **Advanced Usage (CSS/JS Injection):** Because EPL's `paragraph` does not escape HTML entities, it is frequently used to inject custom `<style>`, `<script>`, or raw `<div>` structures directly into the DOM.
*   *Note on Limits:* The EPL lexer (`MAX_TOKEN_LEN`) restricts strings to 256 characters. To inject large blocks of HTML, CSS, or JS, developers must split their injection strings across multiple sequential `paragraph` calls.

## 5. Native 3D WebGL Engine (Three.js)

EPL v1.6 introduced native WebGL scene generation directly from plain English.

### `make canvas3d` ... `!`
Initializes a full 3D rendering context (Three.js scene, camera, renderer). Must be closed with `!`.

### `orbital "<Name>" radius <Num> color "<Hex>" speed <Num>`
Draws a glowing 3D orbital ring around the center of the canvas.
*   **Example:** `orbital "EarthOrbit" radius 100 color "#4ade80" speed 0.05`

### `task node "<Name>" orbit "<OrbitName>" angle <Num> color "<Hex>"`
Generates an interactive 3D sphere attached to a specific orbital ring.
*   **Example:** `task node "Satellite_1" orbit "EarthOrbit" angle 45 color "#ffffff"`

### `link node "<Node1>" to "<Node2>" color "<Hex>"`
Draws a dynamic 3D line connecting two moving task nodes.
*   **Example:** `link node "Satellite_1" to "Satellite_2" color "#ff0000"`
